# ペイント 98

Windows 98 の「ペイント」を Mac で。Swift + AppKit のネイティブアプリです（Electron などは使っていません）。

## できること

- **クリップボードから貼り付け（⌘V）**
  - 新規のまっさらなキャンバスに貼ると、キャンバスが**画像とぴったり同じ大きさ**になる。そのまま編集・保存できる
  - 画像がキャンバスより大きいときは、キャンバスを広げて左上に置く
  - キャンバスの方が広いときは画像が浮いた状態で置かれる。**ドラッグか矢印キー**（shift で 10 ピクセルずつ）で位置を決めて、外側をクリックか return で確定
  - **位置を指定して貼り付け…（⇧⌘V）**：座標の入力か、9 か所（左上・中央・右下など）のボタンで位置を決める
  - **新規画像として貼り付け（⌥⌘V）**：クリップボードの画像をそのまま新しいキャンバスにする
  - スクリーンショット、ブラウザでコピーした画像、Finder でコピーした画像ファイルに対応
- **コピー（⌘C）・切り取り（⌘X）**：範囲選択・自由選択で選んだ部分。選択していなければ画像全体をコピー
- **文字入れ**：ドラッグで枠を作るかクリックして入力。日本語入力 OK。フォント・サイズ・太字・斜体・下線を「フォント」パネルで変更。「なめらか」をオフにすると Win98 風のギザギザ文字。背景は不透明・透明を選べる
- **Skitch ツールバー**（ウインドウ上部。ペイントの道具箱とは別）
  - 矢印・文字・四角（角の丸い太枠）・スタンプ（✕ ✓ ? ! ★ ♥）。どれも白ふち＋影
  - 色は Skitch 専用の 8 色（最初はビビッとな赤 #EB456E）。太さ・文字の大きさ・スタンプの種類もここで
  - 置いた直後は浮いていて、つまみで形・大きさを直せる。delete で削除、矢印キーで移動、外側クリックで確定
- 道具 16 種：自由選択・範囲選択・消しゴム（右ドラッグでカラー消しゴム）・塗りつぶし・色の選択・拡大・鉛筆・ブラシ（4 形状×3 サイズ）・エアブラシ・テキスト・直線・曲線・四角形・多角形・楕円・角の丸い四角形
- 選択範囲：移動、option+ドラッグで複製、ハンドルで伸縮、透明モード（背景色を透かす）、選択範囲でトリミング
- イメージ：反転と回転、伸縮、色の反転、キャンバスのサイズ（右下の青い点のドラッグでも可）、イメージのクリア
- 拡大表示（25%〜8 倍）とグリッド、元に戻す／やり直し（50 回）
- 保存：PNG / JPEG / BMP / GIF / TIFF。画像ファイルをウインドウにドロップで開く（option+ドロップでその位置に貼り付け）

## 入れ方

[Releases](../../releases/latest) から `Paint98.zip` をダウンロードして展開し、`Paint98.app` を「アプリケーション」へ。

Apple の公証を受けていないので、初回だけ次のどれかが必要です。

- macOS 14 以前：アプリを右クリック →「開く」→「開く」
- macOS 15 以降：一度開こうとしたあと、システム設定 → プライバシーとセキュリティ →「このまま開く」
- ターミナル：`xattr -dr com.apple.quarantine /Applications/Paint98.app`

## 自分でビルドする

Xcode か Command Line Tools が入った Mac で:

```sh
./scripts/build-app.sh            # Apple シリコン + Intel 両対応
ARCHS=arm64 ./scripts/build-app.sh # 自分の Mac 用だけ（速い）
open dist/Paint98.app
```

## 構成

| 場所 | 中身 |
| --- | --- |
| `Sources/PaintCore` | 描画・道具・選択範囲・貼り付けのルール・元に戻す。UI に依存しない純粋な Swift（Linux でもテストできる） |
| `Sources/Paint98` | AppKit のアプリ本体（ウインドウ、メニュー、クリップボード、文字入れ、ファイル入出力） |
| `Tests/PaintCoreTests` | PaintCore の単体テスト |
| `.github/workflows/build.yml` | push ごとに Mac でテスト → ビルド → 自己テスト → Releases に `latest` として公開 |

自己テスト（`Paint98 --selftest <出力先>`）は本物のウインドウとクリップボードを使って、貼り付け・コピー・文字入れ・保存を一通り試し、画面のスナップショットを書き出します。
